Case study · SEO & AI Visibility

SEOPlus!, the full SEO audit, AI visibility included, delivered in 30 seconds with its action plan.

SEOPlus! was born in-house: an engine built to make our own client SEO audits reliable and fast, then industrialized into an online product open to everyone. You enter a URL, the engine reads the homepage and up to five key pages, runs 160 factual checks across 16 categories, measures the performance visitors actually experience, and returns a score out of 100, a verdict and a prioritized action plan. No jargon, and with the fixes included.

01 The engine, from URL to report

A fully automated chain, triggered by entering a URL. Scores come from verifiable measurements, never from an AI's imagination.

01

Collection

Homepage and up to five key pages, robots.txt, sitemap, DNS and server headers fetched live.

02

Checks

160 deterministic checks across 16 categories: structure, content, security, email, AI visibility, compliance.

03

Performance

Core Web Vitals measured through Google PageSpeed: real field data when it exists, lab data otherwise.

04

AI verdict

A language model writes the verdict and the competitive read. It comments on the measurements, it never invents them.

05

Report

Score out of 100, grade, 4-phase action plan, per-category detail and fix files ready to drop in.

Collection
Many sites only respond on one variant of their address (with or without www): the engine detects the right origin before auditing, so it never grades a site on an empty page. It follows redirects and reads the real content of each page, not just the tags.
Checks
Every check is deterministic and traceable: robots.txt, sitemap, structured data, security headers, email configuration (SPF, DMARC), heading consistency... A finding is a measurement and a fix, never an impression.
AI visibility
Eleven checks dedicated to how readable the site is for ChatGPT, Perplexity and Google AI Overviews: llms.txt file, structured data, citable passages, quantified facts. The category where even good sites hit a ceiling, and that almost nobody audits.
Score
The final grade weights categories by their real impact: technical structure weighs four times more than the legal notice. The methodology is public, detailed on a dedicated product page.
Report
The full report adds the 4-phase plan, Core Web Vitals, a head-to-head with a competitor of your choice and the missing files generated for the audited domain: robots.txt, sitemap.xml, llms.txt, structured data, server headers, SPF, DMARC. Copy-paste ready, PDF export included.

02 What makes it a product, not a gadget

An automated audit without safeguards is a toy. SEOPlus! is built like a service: reliable, frugal, and honest about what it measures.

Reliability
Every check has been validated against a deterministic oracle that re-derives the result from raw HTTP responses: zero false positives tolerated. If a link in the chain fails, the system falls back and sends a diagnostic alert on its own.
Controlled cost
A 24-hour cache per site, a per-address analysis limit and a single language model call per audit: the service runs for a few euros a month, whatever reasonable traffic you send it.
Sovereignty
The report locates the site's server on a world map and flags hosting outside the European Union: a GDPR angle business leaders understand immediately. The service's own data is hosted in Paris.
Leaderboard
Any audited site can, with a single checkbox, join a public leaderboard of top scores: social proof for the product, a badge to display for well-kept sites.
